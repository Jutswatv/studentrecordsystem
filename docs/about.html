About this demo

Explore the Grade 12 student record management interface.

School year 2026-2027

A preview you can explore anywhere

This GitHub Pages site demonstrates the interface of the Grade 12 Student Record Management System. All student names, demo IDs, grades, and statistics are fictional. No administrator accounts or real student records are published.

Run the complete application

The full HTML, CSS, and PHP application includes secure login, registration, editing, deletion, quarterly grades, CSV export, printable profiles, and account settings. It requires PHP 8.2+ and SQLite; GitHub Pages serves static files only.
